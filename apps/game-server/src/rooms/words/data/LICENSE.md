# DASwords dictionary — sources and licences

`dascade-words.txt` is DASwords' local, server-side dictionary (≈169,000 words, lowercase a–z, 3–15 letters).
It is loaded only by the game server (`../dictionary.ts`) and is never sent to browsers. Gameplay uses no
external dictionary API.

It is generated by `scripts/words/build-dictionary.ts` from:

1. **ENABLE2K** (Enhanced North American Benchmark LExicon), M. Cooper / Alan Beale et al. —
   **public domain**: "The ENABLE master word list, WORD.LST, is herewith formally released into the Public
   Domain. Anyone is free to use it or distribute it in any manner they see fit. … Game designers may feel free
   to incorporate the WORD.LST into their games. Please mention the source and credit us as originators of the
   list." — Thank you, ENABLE authors.
   Source used: https://raw.githubusercontent.com/dolph/dictionary/master/enable1.txt

2. **SCOWL** (Spell Checker Oriented Word Lists), levels 10–50 of the English, American and British lists,
   Copyright 2000-2016 by Kevin Atkinson, via the `wordlist-english` 1.2.1 npm package (MIT-licensed code,
   SCOWL-licensed data). SCOWL's permissive licence requires its copyright and permission notice to accompany
   copies: it is reproduced verbatim in [`SCOWL-Copyright.txt`](./SCOWL-Copyright.txt) (it also carries the
   notices of the public-domain 12Dicts, Moby Words II and UK frequency lists, and the WordNet 1.6 notice used for
   inflections).

3. **DASwords supplement** — ~90 everyday modern words neither list has ("app", "wifi", "selfie", "whiteboard"),
   written for DASwords (generic words only, no trademarks). See `SUPPLEMENT` in the build script.

## Tiers

| Tier | Meaning | Source |
|---|---|---|
| `[1]` everyday | well-known words: anagram seeds, chain words, "missed words" | SCOWL ≤ 35 + supplement |
| `[2]` familiar | valid, less common | SCOWL 40–50 |
| `[3]` rare | valid, obscure (earns the Rare bonus in Anagram Sprint) | ENABLE only |

## Office-safe filtering

Profanity, sexual vocabulary and slurs listed in `packages/game-core/src/words/blocklist.ts` are removed when
the file is generated, and the server checks the same blocklist again at runtime. A handful of SCOWL internet-slang
fragments are excluded as well (`SCOWL_EXCLUDE` in the build script).

## Regenerating

```
curl -LO https://raw.githubusercontent.com/dolph/dictionary/master/enable1.txt
curl -L https://registry.npmjs.org/wordlist-english/-/wordlist-english-1.2.1.tgz | tar xz
pnpm exec tsx scripts/words/build-dictionary.ts enable1.txt package
```

The production build copies this folder next to the server bundle (`apps/game-server/build.mjs` →
`dist/words-data/`).
