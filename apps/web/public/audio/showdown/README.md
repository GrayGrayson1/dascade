# DAS Survey Showdown — recorded sounds

These files override the show's procedural voices (`SHOWDOWN_SOUND_FILES` in
`apps/web/src/games/showdown/sounds.ts`). Each was trimmed, filtered below ~70 Hz where noted, leveled to the
show's loudness budget (AUD-01: peaks under −6 dBTP) and re-encoded as MP3 (48 kHz) with its tags removed.
A file that fails to load falls back to its procedural voice. The repo is public: only sounds we have the
rights to redistribute belong here.
